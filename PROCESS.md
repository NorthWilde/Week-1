# Week-1
As a designer, I used to think of programming as something mainly for programmers. My job was to think about visual style, interaction, composition, and user experience, then programmers would turn those ideas into working products. However the development of AI coding tools has made this boundary less clear. Today, i can describe what i want in natural language and ask an AI to generate a piece of code within seconds. If machines can already write code for us, why should designers still learn programming?
