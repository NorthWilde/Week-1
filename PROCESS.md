# Initial Understanding
The starting point of this assignment was the question: why should designers learn programming when AI can already generate code from natural-language instructions?

Before developing my essay, I watched Dylan Beattie's The Art of Code. The video helped me think about programming from a different perspective. This became an important starting point for my reflection. I also connected the topic to my own experience with Digital Media Art and interactive tools such as Unity, Unreal Engine, Blender, and Figma.
