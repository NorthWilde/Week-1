# Initial Understanding
The starting point of this assignment was the question: why should designers learn programming when AI can already generate code from natural-language instructions?

Before developing my essay, I watched Dylan Beattie's The Art of Code. The video helped me think about programming from a different perspective. This became an important starting point for my reflection because my background is in Digital Media Art. I am more familiar with visual design, 3D modelling, animation, interface design, and interactive media than with traditional programming.
